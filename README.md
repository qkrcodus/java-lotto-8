# java-lotto-precourse
### 입력
- 로또 구입 금액
- 당첨 번호 6개 (쉼표로 구분)
- 보너스 번호 1개 

### 출력
- n 개의 구매 로또 번호 목록 (오름 차순 정렬)
- 등수별 당첨 개수
- 총 수익률

### Lotto 클래스
- 6개의 숫자를 갖는다.
- 로또 번호는 오름차순으로 정렬된다.
- 로또 번호는 정확히 6개여야 한다. (예외: 6개가 아닌 경우)
- 로또 번호는 1~45 범위의 숫자여야 한다. (예외: 범위 벗어난 경우)
- 로또 번호는 중복되지 않아야 한다. (예외: 중복된 경우)

### LottoComparator 클래스
- 로또가 당첨 번호와 일치하는 개수를 반환한다.
- 로또가 보너스 번호를 포함하는지 확인한다.

### Rank 클래스
- 당첨 등수 정보(상금, 조건)를 저장한다.

### WinningLotto 클래스
- 당첨 번호 6개와 보너스 번호 1개를 가진다.
- 보너스 번호는 1~45 범위여야 한다. (예외: 범위 벗어난 경우)
- 보너스 번호는 당첨 번호와 중복되지 않아야 한다. (예외: 중복된 경우)
- 구매한 로또의 당첨 등수를 판정한다.

### LottoMachine 클래스
- 지정된 개수만큼 로또를 랜덤으로 발행한다.

### LottoResult 클래스
- 당첨 결과를 수집하고 통계를 계산한다.
